## What's new in Keymail 1.0.10

**Connecting Claude Desktop now sticks**
If Claude Desktop is open when you click Add to Claude Desktop, Keymail asks you to quit it and adds itself the moment it closes. Before, Claude Desktop could quietly undo the change.

**See what's connected**
Settings → MCP now shows a green check and "Connected" next to Claude Desktop, Claude Code, Codex and Gemini CLI once they're set up to use Keymail.
