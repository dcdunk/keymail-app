## What's new in Keymail 1.0.40

**Calendar**
- Month view now scrolls smoothly, one week at a time, like a continuous page. Swipe or scroll and it rests on whatever week you stop at.
- The month's name shows large while you scroll, then fades away.
- Events can be set to all day when you create or edit them.

**Packages**
- Optional live tracking: if you run your own package-tracking server, add it in Settings → Packages and Keymail checks the carrier's latest status for packages on the way, about every 30 minutes. Delays and missed deliveries show right in the list, along with the carrier's latest scans.
- It's off unless you set it up, and only tracking numbers are sent, only to your server.
