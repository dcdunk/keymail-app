## What's new in Keymail 1.0.23

**Cleaner replies**
When you reply, the people you're writing to now show as name chips, the same as addresses you type yourself. Names with a comma, like "Laura-Beth Fitzpatrick, Psy.D.", stay in one piece instead of breaking into a chip and stray text.

**Reply card fits**
A reply written inside the conversation now grows to fit everything in it, so a large signature no longer cuts off the From line or the Send button.

**iCloud stays signed in**
iCloud sometimes turns down a good password for a moment. Keymail now waits a few minutes and tries again. It only signs the account out if the password is refused three times in a row.
