## What's new in Keymail 1.0.4

**Sending works with pasted addresses**
Some emails wouldn't send and showed "Invalid To header". Keymail now cleans up recipients before sending, so these all just work:
- Addresses pasted from Outlook, which are separated by semicolons
- Addresses copied from a link (starting with "mailto:")
- Two addresses separated by a space
- An accidental space inside an address

**Clearer messages when an address isn't right**
If a recipient isn't a complete email address, Keymail tells you which one before sending, and your draft stays open so you can fix it.
