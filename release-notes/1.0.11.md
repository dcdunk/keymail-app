## What's new in Keymail 1.0.11

**Connections that stay current**
Settings → MCP only shows "Connected" when Claude Desktop, Claude Code, Codex or Gemini CLI is set up to use the Keymail you're running. If you moved Keymail, for example into Applications, the button comes back so you can reconnect in one click.

**Reconnecting from Terminal just works**
The copied commands for Claude Code, Codex and Gemini CLI now replace an older Keymail connection instead of stopping with an "already exists" error.

**Sample calendar fix**
The demo calendar's sample week now follows your "Week starts on" setting, so it no longer looks empty on Sundays.
